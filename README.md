# Linux Simulator v0.1

A browser-based Linux desktop simulator inspired by LinuxSim.

## Included
- Ubuntu-style browser desktop
- Draggable windows
- Terminal
- Files application
- Text editor
- Settings
- Shared virtual filesystem
- Browser persistence using localStorage
- Common commands including `ls`, `cd`, `pwd`, `mkdir`, `touch`, `cat`,
  `echo`, `cp`, `mv`, `rm`, `rmdir`, `chmod`, `grep`, `find`, `head`, and `tail`

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload `index.html` and `README.md` to the root of your repository.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Click **Save**.

This project is a simulation and does not contain a real Linux kernel.
