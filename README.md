# STC Linux Simulator v0.2

Browser-based educational Linux desktop simulator.

## v0.2
- Ubuntu-inspired desktop
- Applications menu
- Terminal, Files, Text Editor, and Settings
- Shared persistent virtual filesystem
- Added `man`, `id`, `groups`, and safe `sudo` behavior
- Draggable application windows
- Student-oriented desktop branding and help cue

## GitHub Pages
Upload `index.html` and `README.md` to the repository root, replacing the previous versions.

This is an educational simulation, not a real Linux kernel or virtual machine.
